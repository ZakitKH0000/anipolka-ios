# Работа с АниПолкой

- По прямому указанию владельца от 23 октября 2026 обновлённую версию приложения нельзя собирать без его явного согласия на сборку. Не запускайте Xcode-сборку, упаковку нового IPA или workflow `.github/workflows/ios.yml` до такого согласия.
- Push в `main` запускает этот workflow автоматически. Не отправляйте туда изменения до разрешения на сборку. Подготовка исходников, тестов, локальная статическая проверка и проверки публичных API разрешены.
- Не включайте личную коллекцию, резервные копии телефона, его идентификаторы и снимки экрана в публичный репозиторий. Для них используется игнорируемая папка `local-private/`.
