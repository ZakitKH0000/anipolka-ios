# Установка АниПолки на iPhone с Windows

Файл `AniPolka-unsigned.ipa` — Release ARM64 для настоящего iPhone с iOS 17 или новее. Он не подписан; нажатием на файл установить его нельзя. LumaSwipe остаётся отдельным приложением.

1. Скачайте IPA из репозитория → Actions → успешная «Сборка и проверка АниПолки» → `AniPolka-unsigned-IPA`. Распакуйте ZIP. Локальная готовая копия также передаётся вместе с итогом сборки.
2. Используйте свой инструмент подписи. Для [Sideloadly на Windows](https://sideloadly.io/) установите необходимые компоненты Apple по его официальной инструкции, подключите разблокированный iPhone по USB и подтвердите доверие компьютеру.
3. Выберите iPhone в Sideloadly и перетащите `AniPolka-unsigned.ipa`. Apple Account вводится только непосредственно в вашем инструменте подписи; не передавайте пароль, сертификаты или коды в чат и GitHub.
4. Выполните подпись и установку. При запросе iOS разрешите профиль в Настройки → Основные → VPN и управление устройством. Для development-подписи может потребоваться Режим разработчика в Настройки → Конфиденциальность и безопасность и перезагрузка.
5. Срок личной подписи и обновления определяет ваш инструмент/профиль. Для бесплатного Apple Account обычно требуется обновление подписи через семь дней. Подробности и текущие требования проверяйте в документации инструмента.

Обновляйте поверх установленной АниПолки с тем же bundle ID `com.zakitkh.anipolka` и способом подписи. Не удаляйте приложение для обновления, иначе потеряете локальную коллекцию. Перед обновлением сохраните копию в Файлы.

## Первое использование

Откройте Коллекция → «+» и найдите произведение. Сверьте год, оригинальное название и обложку, затем выберите, укажите привычное имя и последнюю просмотренную серию. Никакой сезон не угадывается автоматически. Можно вести сквозной номер без сезона.

Кнопка «+1» сразу сохраняет прогресс; снизу на шесть секунд появляется «Отменить». Нажмите карточку → «Изменить», чтобы исправить номер, добавить заметку, ссылку, избранное или свою обложку. Нажатие на загруженную обложку не ищет произвольную картинку.

## Перенести исходный список

Настройки → «Импорт текстового списка». Вставьте текст из Заметок или откройте UTF-8 `.txt` из Файлов. Одна строка: `Название 24`. Нажмите «Проверить список», отредактируйте распознанные названия и номера, снимите флажки с ненужных записей и подтвердите добавление. При отсутствии номера исходная строка сохраняется целиком, серия — 0, с предупреждением. Звёздочка в названии сохраняется и включает избранное.

После импорта откройте запись → «Изменить» → «Найти произведение / сменить обложку». Приложение оставит ваше название и прогресс. При сходных названиях выбираете именно вы.

## Резервная копия и сеть

Настройки → «Сохранить копию в Файлы». JSON содержит прогресс, порядок, настройки и загруженные обложки. Для переноса на другое устройство выберите «Восстановить из Файлов», проверьте список и объедините либо явно подтвердите замену. При объединении существующие записи с теми же UUID сохраняются, новые добавляются; настройки не меняются. Повреждённая копия не очищает коллекцию.

В режиме «Обложки только через Wi-Fi» незагруженные изображения ждут Wi-Fi. Все уже сохранённые обложки и прогресс доступны без интернета. Метаданные поиска могут использовать мобильную сеть. Внешние сайты по вашим ссылкам используют собственные сетевые настройки.

Системные настройки доступности применяются к оформлению. На iOS 26+ используется нативное Liquid Glass; на iOS 17–18 — системный материал. При уменьшении прозрачности фон контролов становится непрозрачным.
