# АниПолка для Android

Перенос iOS-приложения на Kotlin и Jetpack Compose: тот же тёмный дизайн, те же функции, без сервера. Пакет `com.zakitkh.anipolka`, Android 8.0+ (API 26), собирается под API 35.

## Совместимость с iPhone

Файл коллекции и резервные копии в точности того же формата, что пишет iOS-версия: даты, обложки (Base64), идентификаторы, необязательные поля. Копию из iPhone (Настройки → «Сохранить копию в Файлы») можно открыть на Android (Настройки → «Восстановить из файла») и наоборот. Это проверяет тест `readsACollectionWrittenByTheIOSApp`.

## Что перенесено

- «Витрина»: «Продолжить» с прогрессом, «Сегодня выходит», фильтры (избранное, статусы, «Есть новые серии», метки, озвучки), сетка карточек одной высоты, список, группы по статусам.
- Мастер добавления из 4 шагов: поиск сразу в Shikimori и Kitsu, прогресс, «Где смотрю» (подбор страницы AniVibe, любимые озвучки), «Готово».
- Карточка: атмосфера обложки, оценка, «Где остановился», «Где смотрю», связанные части, история по тайтлу, пересмотр, премьера, «+1» с долгим нажатием (+2/+3/+5/до серии N) и отменой.
- Редактор, автообложки (заглушки «404» отбрасываются, резервный Kitsu), своя обложка из галереи.
- «Серии», «Неделя», источники AniVibe, фоновые проверки (WorkManager), уведомления с кнопкой «+1», сводка в дни выхода и премьеры.
- Итоги, карточка года, «Текст для копирования», импорт текста, ручной порядок, «Что посмотреть?».
- Виджет «Продолжить просмотр», плитка «+1 серия» в шторке, ярлыки на значке, «Поделиться → АниПолка», блокировка отпечатком или PIN, три иконки, OLED-тема.

## Дизайн в стиле iOS 26

- Плавающая стеклянная панель вкладок («жидкое стекло»): размытие содержимого под ней, подсветка выбранной вкладки скользит с пружиной, красный счётчик новых серий.
- Крупные заголовки; при прокрутке появляется маленький заголовок над размытой полосой. Круглые стеклянные кнопки «‹», «+», «Изменить», синяя «Сохранить».
- Настройки и списки — сгруппированные карточки с отступами разделителей, шевронами, меню выбора ⌃⌄ и переключателями iOS.
- Переходы между экранами — сдвиг справа, как в iOS; позиция прокрутки сохраняется при возврате.
- Размытие делает библиотека Haze (`dev.chrisbanes.haze`) и работает на Android 12+; на старых версиях стекло показывается полупрозрачной заливкой. Код компонентов — `ui/Glass.kt`.

## Отличия от iOS

- Виджет и плитка работают в процессе приложения, общая папка (App Group) не нужна.
- «Поделиться» — настоящий пункт системного меню, без «Команд».
- Siri заменена ярлыками на значке и плиткой в шторке.
- Сводка и премьеры приходят через WorkManager: возможна задержка в несколько минут.

## Сборка

Нужны JDK 17+ и Android SDK 35. На этом компьютере используются JDK из `C:\dev\phonedesk-tools\jdk` и SDK из `C:\dev\Android\.tools\sdk` (путь в `local.properties`, файл не хранится в Git).

```
gradlew.bat :app:testDebugUnitTest :app:assembleRelease
```

Release собирается с R8 и подписывается локальным отладочным ключом, чтобы ставиться по USB.
