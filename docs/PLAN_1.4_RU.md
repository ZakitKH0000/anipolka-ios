# План АниПолки 1.4 (выбрано владельцем 21 ноября 2026)

Без ИИ и без ключей. Сейчас только iPhone (Android отложен владельцем). Каждый этап: iOS → специальная сборка (DEV_REMOTE) → проверка на iPhone по Wi-Fi → перенос на Android.

## Этап 1. Сезоны, просмотр, студия
- [x] Белая полоса на фоне карточки (размытие обложки).
- [x] Франшизы из Shikimori (`franchise`): одна карточка на франшизу на главном экране, вкладки сезонов в карточке, части не из коллекции — «Добавить».
- [x] Нумерация выбирается для франшизы: по сезонам (по умолчанию) или сквозная; смещение сезона рассчитывается и правится вручную.
- [x] Переход к следующему сезону: «Сезон досмотрен — начать следующий?».
- [x] «Догнать к выходу»: сколько серий в день до выхода следующей части.
- [x] Встроенный просмотр AniVibe (Kodik/Bunny): нужная серия и озвучка, авто «+1» по окончании, «Где остановился» с минутой, следующая серия, PiP/AirPlay, блокировка рекламных переходов.
- [x] Студия: «Предложить / Ошибка» (текст + снимок экрана + место), выгрузка по Wi-Fi; «Что нового»; «Лаборатория».
