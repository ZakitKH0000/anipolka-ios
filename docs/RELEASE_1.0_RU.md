# АниПолка 1.0

Нативная коллекция аниме и дунхуа для iPhone: обложки выбранных произведений, последняя просмотренная серия и быстрый «+1» с отменой. Есть четыре статуса, независимое избранное, заметки, ссылки, поиск по своей полке, ручной порядок, список и сетка.

Поиск каталога Shikimori работает без обязательного аккаунта или платного ключа. Варианты произведений и сезонов выбирает пользователь. Привычные названия и сквозная нумерация сохраняются; доступны собственные обложки и другие изображения выбранного произведения.

Тёмное оформление включено по умолчанию; светлое и системное тоже доступны. Системное Liquid Glass на iOS 26+, поддержка крупных шрифтов и уменьшения прозрачности. Обложки можно ограничить Wi-Fi; сохранённая коллекция работает офлайн.

Текстовый список переносится с проверкой и исправлением строк перед добавлением. Резервная копия в Файлы включает прогресс, порядок, настройки и загруженные обложки. При восстановлении можно объединить коллекции или подтвердить замену; повреждённая копия не очищает текущие данные.

## Скачать и установить

В Assets этого релиза выберите **AniPolka-unsigned.ipa**. Это Release ARM64 для настоящего iPhone с iOS 17+, bundle ID `com.zakitkh.anipolka`. Перед установкой подпишите его своим инструментом на Windows. Подробности — в приложенном `INSTALL_RU.md`. Apple ID и сертификаты в GitHub или чат передавать не нужно.

`SHA256.txt` содержит контрольную сумму именно этого файла. `AniPolka-simulator-screenshots.zip` содержит реальные снимки симулятора с тестовыми названиями и иллюстрациями, а не официальными обложками. При обычном запуске коллекция пустая.

[Результаты проверок и границы проверки на устройстве](https://github.com/ZakitKH0000/anipolka-ios/blob/main/docs/VERIFICATION_RU.md).

Личные записи пользователя в релиз не включены. LumaSwipe остаётся отдельным приложением. Face ID, виджеты, напоминания и синхронизация не добавлялись.
