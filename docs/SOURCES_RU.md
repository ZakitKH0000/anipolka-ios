# Источники в АниПолке 1.1

Проверено 23 октября 2026. Приложение — помощник для коллекции и уведомлений. Оно не содержит рекламного SDK, встроенного видеоплеера или загрузчика видео. Реклама на внешнем сайте определяется самим сайтом.

## Что подключено

**Shikimori** — основной поиск русских и оригинальных названий, постеры и альтернативные изображения выбранной карточки. [Документация](https://shikimori.io/api/doc), [поиск](https://shikimori.io/api/doc/1.0/animes/index). Ограничение приложения — один запрос в секунду; HTTP 429 включает паузу. Автоматически выбирается только одно точное совпадение названия после нормализации регистра, ё/е, пробелов и знаков. Сезоны и опечатки не угадываются. При неоднозначности остаётся ручной выбор.

**Kitsu** — дополнительный каталог обложек. [Документация API](https://kitsu.docs.apiary.io/), [сайт](https://kitsu.app/). Живой поиск `Tunshi Xingkong` вернул китайский сериал, отдельные сезоны и связанные постеры. В поиске приложения можно переключить каталог; Kitsu особенно полезен с оригинальными/английскими названиями. Автообложки обращаются к нему, если Shikimori не вернул результатов или недоступен. ID каталогов не смешиваются: выбор Kitsu не подставляет его ID в Shikimori или AniVibe.

**AniVibe** — выход новых серий по выбранной публичной странице [произведения](https://anivibe.pro/). Читается ограниченный HTML (до 8 МБ), из него — только JSON с названиями дорожек и номерами серий. Не выполняется JavaScript, не вызываются закрытые `/api/`, не извлекаются/сохраняются видеоссылки, коды файлов и `signed_params`. Ограничение чтения — одна страница за 1,2 секунды, одинаковые страницы в одной проверке читаются один раз.

На одной странице Kodik может показывать 26 серий первого сезона, а AniVibe — 246 по сквозной нумерации. Поэтому сохраняется конкретная дорожка, её язык/тип или сезон. Варианты не объединяются по приблизительному названию. Ссылка уведомления использует публичные параметры сайта `episode`, `translation`, `player`; Kodik принимает название озвучки, AniVibe — ключ `type||language||author`. Сайт сам открывает плеер; его доступность зависит от региона, браузера и прав на контент.

При подключении исходный номер запоминается без рассылки старых выпусков. Далее увеличение создаёт одну запись о последней новой серии с предыдущей отметкой источника. Наличие всех промежуточных серий не предполагается. Повторная проверка не дублирует запись. Уменьшение номера, исчезновение дорожки и сетевые ошибки сохраняют предыдущую отметку и показывают ошибку. Просмотренная серия, имя и заметки пользователя не изменяются.

## Работа без сервера

Используются `BGAppRefreshTask` и локальные `UserNotifications`. [Apple: выбор фоновой стратегии](https://developer.apple.com/documentation/backgroundtasks/choosing-background-strategies-for-your-app). Запрашивается запуск не раньше чем через шесть часов, фактическое время выбирает iOS. Проверки не являются таймером; мгновенные уведомления не обещаются. В фоне за один запуск обрабатываются до восьми наиболее давно проверенных подписок; недавно проверенные пропускаются. Ручная проверка обрабатывает до 60 подписок, следующие запускаются повторным нажатием. Всегда доступна кнопка «Проверить сейчас».

Уведомления требуют явного включения и системного разрешения. Если разрешение отключено, найденные выпуски сохраняются во вкладке «Серии». Принудительное закрытие приложения, режим энергосбережения и запрет фонового обновления могут помешать проверкам. Работа фонового планировщика и нажатия на уведомление после личной подписи требуют отдельного испытания на телефоне.

## VK

Проверенные публичные страницы VK Видео в этой среде возвращали повторные перенаправления, без надёжного списка роликов. Их пустой ответ не считается отсутствием новых серий. Не добавлен парсер, который выдавал бы такое состояние за успешную проверку.

Официальный [VK ID iOS SDK](https://github.com/VKCOM/vkid-ios-sdk) использует OAuth 2.1 и требует регистрации приложения. По официальным схемам [video.get](https://github.com/VKCOM/vk-api-schema/blob/master/video/methods.json) нужен пользовательский токен; [wall.get/search](https://github.com/VKCOM/vk-api-schema/blob/master/wall/methods.json) поддерживают пользовательский или сервисный токен. Сам вход VK ID не гарантирует разрешения нужных API и доступ к закрытым публикациям. Поэтому вход и автоматическое отслеживание VK в этой версии ещё не доступны. Пароли, токены и client_secret не вшиваются в публичный репозиторий.

## Другие проверенные варианты

- [AniLiberty API](https://api.anilibria.app/api/docs/v1/) содержит релизы, эпизоды и расписание. Полезен для произведений своей озвучки, но не решает недостаточный охват китайских дунхуа. В 1.1 не подключён.
- [AnimeSchedule](https://animeschedule.net/about-us) предлагает расписание, API и RSS. Это календарь выхода, а не подтверждение появления конкретной русской озвучки. API требует регистрации приложения; [документация](https://animeschedule.net/api/v3/documentation). В 1.1 не подключён.
- AniList не используется из-за ограничений [API Terms of Use](https://docs.anilist.co/guide/terms-of-use) на самостоятельные конкурирующие трекеры.

Коллекция хранится локально. Для поиска наружу уходит запрашиваемое название; для проверки серий — только выбранная страница. Резервная копия содержит подписки, исходные номера, найденные выпуски, настройки и уже сохранённые обложки. Старые копии версии 1.0 открываются с настройками по умолчанию для новых функций.
